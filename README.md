# No Summon Aggro (NeoForge 1.21.1)

Player-owned summons from Iron's Spells 'n Spellbooks and any addon built on its `IMagicSummon` API
(Cataclysm: Spellbooks, etc.) no longer target or damage other players, villagers, golems, guards,
pets or other players' summons. Summons owned by hostile mobs are untouched.

Requires Iron's Spells 'n Spellbooks. Downloads: [GitHub Releases](https://github.com/hammerknife404/catspells-nosumagro/releases).

**Documentation:** [the wiki](https://github.com/hammerknife404/catspells-nosumagro/wiki) covers the config
options, protecting more mobs with the entity tag, Neat health bars, and building and releasing.
